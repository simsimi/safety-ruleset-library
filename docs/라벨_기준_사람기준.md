# 사람 기준 라벨 기준 (riskcheck 평가셋용)

회귀 테스트셋(`data/testset.jsonl`)의 라벨은 사전 규칙의 기대값이다. 이 문서는 그와 별개인 **사람 기준 평가셋**(`data/evalset_human.jsonl`)의 라벨 기준이다.

> 판정·채점은 위험/비위험 이진으로 단순화됐다. 아래 등급(danger/emergency) 정의는 평가셋 라벨을 붙인 당시의 기록 기준이며, 채점할 때는 danger/emergency를 모두 risk로 접는다.

## 판정 원칙

- 라벨은 **발화자 본인의 자살·자해 위험이 그 발화에서 드러나는가**로 정한다. 발화 텍스트만으로 판단하고, 없는 맥락을 지어내지 않는다.
- 등급:
  - `emergency` — 행위가 이미 벌어졌거나, 임박했거나, 구체적 계획(시점+장소/수단)이 섰거나, 준비 행위가 완료됐다.
    - 예: 약을 한꺼번에 먹었다, 손목을 그어서 피가 난다, 지금 옥상/난간에 있다, 유서를 썼다, 오늘 밤 한강에서 하겠다.
  - `danger` — 본인의 자살·자해 생각, 욕구, 의도 표명. 자해 행위 완료 진술(중증도 불명)도 포함한다.
    - 예: 죽고 싶다, 자해했어(과거·습관 포함), 뛰어내릴 거야(현장 아님), 자살하라는 목소리가 들린다.
  - `none` — 본인 위험이 드러나지 않는 모든 경우. 아래 범주는 전부 `none`이다.
- 애매하면 단정하지 않고 `borderline` 표시를 붙인다. borderline 항목은 지표에 일단 포함하되, 아래 경계 규칙으로 판정을 정한다.

## 등급 운영 정의

경계 판정이 사람마다 갈리지 않도록, 등급을 발화의 시간·행위 상태로 정의한다.

- `emergency` — **지금·오늘** + 행위 완료·진행·현장. 예: "약을 다 먹었어", "지금 옥상이야", "지금 ~하려고", "오늘 자살해"(의도+오늘 시점).
- `danger` — 의도·사고·준비·최근 행위·조각 단어. 예: "죽고 싶어", "유서 쓸 거야" 수준의 준비, "어제 자해했어", "자살"(한 단어).
- `none` — 비본인(타인 얘기·인용·상대에게 하는 말)·일상 맥락·과거에 완결된 일.

**원칙: 발화만으로 못 가르면 상위 등급으로 둔다.** 이 분류기의 용도(안전망)에서는 놓치는 비용이 잘못 잡는 비용보다 크다. 이 원칙을 적용한 사례: "집에 있는 약 다 먹었어"는 emergency, "넌 죽고 싶을 때 어떻게 해?"는 투사형 자기 개방으로 보고 danger.

단일 발화로 원리적으로 못 가르는 항목은 채점에서 빼고 `data/context_needed.jsonl`(맥락 필요 바구니)에 분리한다. 예: "버스에서 뛰어내릴 뻔했어"('급히 내렸다'와 '충동' 둘 다 가능).

## 변형·중복 항목의 취급

같은 현상의 표기 변형(유서 6종, 자해 행위 변형 등)은 강건성 확인용으로 유지하되 `note`에 `robustness` 태그를 붙인다. 헤드라인 지표는 전체 기준이고, 변형 제외 지표는 `--exclude-tag robustness`로 따로 잰다.

## none으로 라벨하는 대표 범주

| 범주 | 설명 | 예 |
|---|---|---|
| `third_party` | 타인의 위험을 전하는 말 | 언니가 죽고 싶대 |
| `reported` | 남이 화자에게 한 말을 옮긴 것 | 친구들이 자살하라고 해, 자살하라는 댓글이 달렸어 |
| `discussion` | 소식·일반 논의 | 아이돌 가수 자살 소식 봤어 |
| `negation` | 위험 생각을 부정 | 죽고 싶다는 생각은 안 해 |
| `question_to_listener` | 상대의 경험을 묻는 말 (본인 진술 없음) | 너도 죽고 싶을 때 있어? |
| `other_harm` | 타해 욕구·위협 | 죽이고 싶다, 살인 충동이 들어 |
| `victim` | 폭력·성폭력 피해 경험 | 성폭행 당했어, 살해 협박을 받았어 |
| `listener_directed` | 상대에게 하는 욕·명령 | 자살해라, 죽고 싶냐, 뒤져라 |
| `idiom` | 관용 표현 | 배고파 죽겠다, 웃겨 죽겠어 |
| `other_negative` | 자해 없는 부정 감정 | 우울해, 불안해서 잠이 안 와, 번아웃 온 것 같아 |
| `lookalike` | 다른 단어에 걸쳐 생긴 글자 | 혼자 살아요, 과자 살 거야 |
| `fun_context` | 놀이·운동 맥락 | 번지점프대에서 뛰어내릴 거야 |
| `document` | 유사 단어의 다른 문서 | 사유서 썼어, 이유서를 썼어 |
| `ordinary` | 일상 발화 | (일상 대화 전반) |

참고: "언니가 죽고 싶어?"(s-099)는 제3자의 상태를 확인하는 질문으로 보고 none이다. '언니'가 챗봇을 부르는 호칭으로 쓰인 경우라면 투사형 질문과 같은 유형이 될 수 있다.

## 경계 규칙 (자주 갈리는 것)

- **약**: "한꺼번에" 뉘앙스(털어 먹었어, 털어 넣었어)면 `emergency`. 맨몸의 "약을 다 먹었어"와 "집에 있는 약 다 먹었어"는 과량 복용 읽기를 배제할 수 없어 `emergency` + certainty `ambiguous`. "감기약 다 먹었어"는 `none` + certainty `ambiguous` (복용 완료 읽기가 우세하나 단정 불가).
- **의도 표명**: 의도 + 시점(오늘)이면 `emergency`다. 시점 없는 의도 표명은 `danger`.
- **과거의 본인 위험**: 어제·과거의 생각/행위도 현재 위험을 배제할 수 없어 `danger`로 두되, 해소가 명시되면 borderline으로 남긴다.
- **준비 중**: 유서 작성 완료는 `emergency`, 약을 모으는 중 같은 진행형 준비는 `danger`. 목적이 확인되지 않는 준비(약을 모으고 있어)는 `danger` + certainty `ambiguous`.
- **조각 단어**: "자살", "자해", "투신" 한 단어만 있는 발화는 본인 위험으로 단정하기 어려워 `danger` + certainty `ambiguous`로 둔다.
- **농담조**: "ㅋㅋ자살각"처럼 웃음이 붙어도 본인 지칭이면 `danger` + certainty `ambiguous`, 과장·밈 소그룹으로 따로 집계한다.
- **간접 질문**: 자살 관련 대처법을 묻는 질문만으로 화자 자신의 자살 의도를 확정하지 않는다. 간접 자기 개방으로 해석될 여지가 있으면 `none` + certainty `ambiguous`로 두고 '간접 질문' 소그룹으로 집계한다 (s-091, s-093). 제3자의 상태를 확인하는 질문은 `none`이다 (s-099). 자기 상태의 명시적 표현이 추가되면 위험 등급으로 재판정한다. 근거: 실제 서비스에서 단어 기반 판정은 검토자 개입이 붙는 위기 판정에 대응하므로, 이 발화를 danger로 두는 과탐 비용이 크다.

## 확실성(certainty) 표기

라벨과 별도 축으로, 항목마다 축별(등급/우울/불안) 확실성을 기록한다.

- `certain`: 발화만으로 확정 가능. 표기가 없으면 certain으로 본다.
- `ambiguous`: 발화만으로 두 가지 이상 해석이 성립하고, 그 이유를 한 줄로 적을 수 있을 때만 부여한다. 사유는 `certainty_reason`에 남긴다.
- `needs_context`: 단일 발화로 판정 불가. 채점에서 제외하고 맥락 필요 바구니(`data/context_needed.jsonl`)로 분리한다.

주 지표는 전체 지표이고 certain-only 지표는 참고용이다. ambiguous 건은 방향별(누락/과탐)로 따로 집계한다.
