# 로컬 실행 가이드

riskcheck를 본인 컴퓨터에서 직접 돌려보는 절차다. macOS 기준으로 쓴다.

## 0. 준비물

- Python 3.11 이상 (`python3 --version`으로 확인)
- Git (레포를 받을 수 있는 접근 권한)

## 1. 받기와 설치

```bash
git clone <레포 주소>
cd <클론한 폴더>
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

설치가 됐는지 테스트로 확인한다. 32개 통과에 1개 건너뜀이면 정상이다 — 건너뛰는 1개는 로컬 ONNX 실모델 테스트로, 선택 패키지(`.[local-onnx]`)까지 설치하면 33개 전부 돈다.

```bash
python -m pytest -q
# 32 passed, 1 skipped
```

## 2. 발화 하나만 판정해 보기

```bash
riskcheck detect --dict dicts/default.yaml "요즘 진짜 죽고 싶어"
riskcheck detect --dict dicts/default.yaml "배고파 죽겠다"
```

JSON으로 판정(`predicted`)과 걸린 패턴(`matches`)이 나온다. 첫 번째는 risk, 두 번째는 none이 나와야 한다.

## 3. 사전 단계 평가 돌리기

```bash
riskcheck evaluate --dataset data/evalset_human.jsonl --dict dicts/default.yaml --out runs/local
```

- 콘솔에 지표표가 찍히고, 상세는 `runs/local/report_dict.md`(또는 `.html`)에 생긴다.
- 기대값 (사람 기준 평가셋 500건, 기본 사전 0.5.0): 정확도 0.9540, 위험 Precision 0.8333 / Recall 1.0000.
- `data/testset.jsonl`(271건, 규칙 기대값 회귀 셋)으로 돌리면 정확도 1.0000이 나온다 — 규칙 동작 재현 확인용이다.

## 4. 모델 단계까지 돌리기 (스텁 데모)

`models/stub.yaml`은 실제 모델이 아닌 데모용 규칙 스텁이다. 파이프라인과 리포트 형식을 보는 용도다.

```bash
riskcheck evaluate --dataset data/evalset_human.jsonl --dict dicts/default.yaml \
    --model-config models/stub.yaml --out runs/local-stub
```

결과 파일이 3종으로 늘어난다.

| 파일 | 내용 |
|---|---|
| `report_dict.md` | 사전 단계 (이진 판정 지표) |
| `report_model.md` | 모델 단계 (이진 판정 지표 + **하위 라벨 지표**) |
| `report_combined.md` | 통합 판정 |
| `predictions.jsonl` | 단계별 원판정 (재채점용) |

각 리포트는 같은 이름의 `.html`(브라우저용)과 `.json`(기계 판독용)도 함께 생긴다. 사람이 볼 때는 HTML이 편하다.

`report_model.md`의 하위 라벨 표 기대값: 불안 P 0.80 / R 0.69, 우울 P 0.56 / R 0.08.

## 4-1. 기본 모델로 돌리기

기본 모델(감정 모델 + 위해 모델)은 배포 자산으로 제공된다. 추가 패키지 설치와 모델 내려받기가 한 번 필요하다.

```bash
pip install -e ".[local-hf]"
python3 tools/download_models.py   # models/emotion-heads-v1/, models/harm-genuine-v2/ 배치
riskcheck evaluate --dataset data/evalset_human.jsonl --dict dicts/default.yaml \
    --out runs/local-base
```

모델을 지정하지 않으면 기본 모델이 자동 적용돼 사전+위해 모델+감정 모델 전체 구성으로 평가한다. 자기 모델로 점검하려면 `--model-config`와 `--harm-model-config`로 자기 설정 파일을 지정하거나, 기본 설정 파일의 `local.path`를 자기 모델 디렉터리로 바꾸면 된다.

## 5. 임계값만 바꿔 재채점하기

모델을 다시 부르지 않고, 저장된 `predictions.jsonl`에 정책만 새로 적용한다.

```bash
riskcheck evaluate --dataset data/evalset_human.jsonl \
    --predictions runs/local-stub/predictions.jsonl \
    --model-config models/stub.yaml --threshold-anxiety 0.9 --out runs/local-rescore
```

임계값을 올리면 불안 Recall이 떨어지는 식으로 지표가 바뀌는 것을 확인할 수 있다.

## 6. 안 될 때

- `riskcheck: command not found` — 가상환경 활성화(`source .venv/bin/activate`)를 안 한 것이다.
- Python 버전 오류 — `requires-python >= 3.11`이다. `python3.11 -m venv .venv`처럼 버전을 지정해 만든다.
- 클론 권한 오류 — 레포 접근 권한이 있는지, 호스팅 서비스에 인증이 되는지 확인한다.
